# Changelog

All notable changes to this package will be documented in this file.

## [0.2.0] - 2026-08-19

### Added

- Game view capture while the Unity editor is in Edit Mode

### Changed

- The Game view is focused automatically before capture
- The success notification appears only after the PNG file has been created

## [0.1.0] - 2026-08-19

### Added

- F12 shortcut for capturing the Game view in Play Mode
- Shortcut rebinding through Unity's Shortcut Manager
- Configurable screenshot output directory
- Commands for capturing and opening the screenshot folder
- PNG filenames containing the capture date and time
